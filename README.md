# 3X-UI Server Auto-Optimizer & SNI Finder

Универсальный скрипт для быстрой настройки серверов с панелью 3X-UI и протоколом VLESS Reality. 

### Что делает скрипт:
- 🚀 **Автоматически включает BBR + fq** (решает проблему низкой скорости до 5 Мбит/с).
- 🕒 **Синхронизирует время** (критично для TLS handshake в Reality).
- 🌍 **Определяет страну сервера** (Польша, Нидерланды, Германия и др.).
- 🔍 **Подбирает идеальный SNI** (сканирует локальные доверенные ресурсы и соседей по подсети, проверяя на TLS 1.3 и HTTP/2).
